# Histórico de uso de Inteligência Artificial

Durante o desenvolvimento deste desafio, utilizei o ChatGPT como apoio para estruturar o projeto, escrever o código, tratar erros e organizar a entrega.

## Prompts utilizados

1. "Preciso que me ajude a fazer esse desafio, passo a passo, uma coisa de cada vez, seguindo a sequência lógica das coisas."

2. "Escolha uma API pública e gratuita e me ajude a desenvolver um script que consulte essa API para uma lista de 10 entradas e gere um CSV organizado, tratando erros sem quebrar."

3. "Gostaria de hospedar o projeto no GitHub."

4. "Por que tenho que criar um arquivo com o nome main.py?"

5. "Me ajude a criar o código em Python utilizando a API ViaCEP."

6. "Como faço para gerar o arquivo CSV com os resultados?"

7. "Como posso executar o código usando o Google Colab?"

8. "Como coloco o CSV gerado no meu repositório do GitHub?"
